# Astrateq Beta Launch

Build a modern, high-converting pre-launch landing page web app for Astrateq Gadgets based on the provided wireframe, branding guidelines, and logic inside the attached TypeScript file.

Design System & Aesthetics:

- Minimalist Dark-Mode Theme: Deep obsidian (#0A0A0B) background with high-contrast text (#F8FAFC, #94A3B8).

- Accent Colors: Electric cyan/neon telemetry blue (#00F0FF) for buttons, glow highlights, and HUD overlays.

- Visual Vibe: Sleek engineering aesthetic inspired by Tesla, Apple, and high-tech automotive UI. Clean borders, subtle glassmorphism cards, and refined micro-interactions.

Page Layout & Components:

1. Navigation Bar:

   - Left: Minimalist text logo "ASTRATEQ GADGETS" with a subtle cyan dot indicator.

   - Right: "Privacy Whitepaper" link and a primary button "Join Beta Cohort".

2. Hero Section:

   - Headline: "Smart Driver Awareness. Zero Privacy Compromise."

   - Subheadline: "Experience privacy-first driver assistance powered by local Edge AI. Purpose-built for Canadian winter commuters—no cloud streaming, zero surveillance."

   - Primary Call-to-Action: Interactive email waitlist form with an input field and a glowing cyan submission button "Request Early Beta Access".

   - Trust Badge directly below: "🔒 100% On-Device NPU Computer Vision • Purpose-Built for Canadian Winters".

   - Hero Mockup Visual: An interactive dashboard HUD container displaying simulated real-time driver gaze tracking, temperature metrics, and snow-glare exposure adjustments using clean SVG/canvas overlays.

3. Feature Grid (3 Interactive Cards):

   - Card 1 (Privacy & Data Sovereignty): Headline "Edge-AI Execution". Body focusing on local mobile NPU processing, zero raw video streaming to cloud servers, ultra-low latency, and complete data control.

   - Card 2 (Canadian Climate Intelligence): Headline "Snow-Glare & Cold-Weather Vision". Body detailing computer vision calibrated for reflective snow sunlight, winter fatigue monitoring, and cold-weather adaptivity.

   - Card 3 (Future-Proof Ecosystem): Headline "Software to Silicon". Highlighting the evolution from the initial iOS/Android smartphone app to dedicated NPU dashcams, OBD-II diagnostic tools, and TPMS sensors.

4. Beta Waitlist Section (Social Proof & Urgency):

   - Headline: "Join the Canadian Beta Cohort".

   - Sub-banner: Highlighting a limited cohort of 500 TestFlight spots for daily commuters.

   - Perverted benefits breakdown: Priority app access, direct input into feature roadmaps, and locked-in founding rates for future hardware releases.

   - Repeat Email Input form with success state animation.

5. Footer:

   - Clean copyright, privacy policy link, data sovereignty guarantee note, and social links.

Make all components fully responsive (mobile, tablet, desktop) and include subtle hover animations on cards and CTAs.
